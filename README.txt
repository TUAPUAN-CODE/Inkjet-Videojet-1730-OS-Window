i-Tail QR -> Inkjet Sender
==========================

โปรแกรมสแกน QR Code ด้วยกล้อง แล้วส่งคำสั่งใน QR เข้าเครื่อง Videojet 1710 ผ่านสาย LAN
(โปรโตคอล WSI, TCP พอร์ต 3100)

สร้างไฟล์ .exe
--------------
1. ติดตั้ง Python 3.9-3.13 (64-bit) จาก python.org (ติ๊ก "Add python.exe to PATH")
2. ดับเบิลคลิก build_exe.bat  (ต้องต่อ internet ตอน build ครั้งแรก)
3. ได้ไฟล์ dist\iTail-QR-Inkjet.exe  คัดลอกไปใช้บนเครื่องอื่นได้ทันที ไม่ต้องลง Python

ตั้งค่าเครื่อง Videojet 1710 (ครั้งเดียว)
-----------------------------------------
- ต้องมีออปชัน Ethernet และต่อสาย LAN เข้าเครือข่ายเดียวกับคอมพิวเตอร์
- เมนู CONFIGURE > REMOTE : เลือกใช้โปรโตคอลผ่าน Ethernet
- ตั้ง IP ของเครื่องให้อยู่วงเดียวกับคอมพิวเตอร์ (ค่าเริ่มต้นตามเอกสาร 192.168.100.2)
- ข้อความที่พิมพ์ต้องมี User Field ชื่อตรงกับที่อยู่ใน QR (เช่น UF1, UF2)

วิธีใช้
-------
1. ใส่ IP ของเครื่อง Inkjet (พอร์ต 3100) แล้วกด "ทดสอบการเชื่อมต่อ" (ไม่ส่งข้อมูลใดเข้าเครื่อง)
2. เลือกกล้อง กด "เปิดกล้อง"
3. นำ QR Code มาให้กล้องอ่าน โปรแกรมจะตรวจรูปแบบ แล้วส่งให้เครื่องอัตโนมัติ
   (ถ้าไม่ต้องการส่งอัตโนมัติ ให้เอาติ๊ก "ส่งอัตโนมัติ" ออก แล้วกด "ส่งข้อมูล" เอง)
4. ดูผลที่แถบสีเขียว/แดง และในช่อง "ประวัติการส่ง"

รูปแบบข้อมูลใน QR
------------------
ต่อกันเป็นคำสั่ง โดย <STX> ต้นข้อความและ <ETX> ท้ายข้อความโปรแกรมเติมให้เอง (เหมือนที่สแกนเนอร์ทำ)

  M<ชื่อข้อความ><ETX><STX>U<ชื่อfield><LF><ค่า><ETX><STX>U<ชื่อfield><LF><ค่า>

ตัวอย่าง:
  MHALG-101T LOT<ETX><STX>UUF1<LF>A3Z27<ETX><STX>UUF2<LF>66666

  M     = เลือกข้อความ (ชื่อ 1-30 ตัวอักษร)
  U     = ใส่ค่าลง User Field   (ชื่อ field 1-30 ตัว, ค่า 1-50 ตัว, ภาษาอังกฤษ/ตัวเลขเท่านั้น)
  <LF>  = ตัวขึ้นบรรทัดใหม่ คั่นระหว่างชื่อ field กับค่า (ขาดไม่ได้)

ความปลอดภัย
-----------
- ตรวจทุกคำสั่งก่อนส่ง ถ้ามีคำสั่งใดผิดรูปแบบจะไม่ส่งเลยสักคำสั่ง
- รับเฉพาะคำสั่ง M และ U (คำสั่งอย่างหยุดหัวพิมพ์ จะถูกปฏิเสธ)
- ถ้าเครื่องปฏิเสธคำสั่งใด จะหยุดส่งคำสั่งที่เหลือทันที และแจ้งเป็นสีแดง
- QR ใบเดิมที่ยังค้างอยู่หน้ากล้อง จะส่งเพียงครั้งเดียว ต้องนำออกจากหน้ากล้องเกิน 2 วินาที แล้วนำมาสแกนใหม่จึงจะส่งอีกครั้ง

ไฟล์ที่โปรแกรมเก็บ  (%APPDATA%\iTail-QR-Inkjet)
-----------------------------------------------
  config.json    ค่า IP / Port / กล้อง
  send_log.txt   บันทึกทุกครั้งที่สแกน (เวลา | ผล | ข้อมูล | รายละเอียด)

แก้ปัญหาเบื้องต้น
-----------------
- เปิดกล้องไม่ได้       : เลือก "กล้องที่" อื่น / ปิดโปรแกรมอื่นที่ใช้กล้อง (Teams, Zoom)
- สแกนแล้วขึ้น "ขาด <LF>" หรือ "ขาด <ETX>" : QR ถูกสร้างผิดรูปแบบ ให้แก้ที่โปรแกรมออกแบบฉลาก
- เชื่อมต่อไม่ได้       : ตรวจสาย LAN, IP, เมนู REMOTE ของเครื่อง และ Firewall ของ Windows
- เครื่องตอบ !XX         : เครื่องปฏิเสธคำสั่ง (เช่น ไม่มีชื่อข้อความ/Field นั้นในเครื่อง)
